    Enable Gemini Nano in Chrome
    1. Use Chrome Canary or a Chrome build that exposes the built-in Language Model APIs.
    2. Open chrome://flags, search for built-in AI or Prompt API flags, and enable the Gemini Nano / language model flags available in your build.
    3. Restart Chrome, then open this popup again. CraveLens will use Gemini Nano only when Chrome exposes the required image-capable API.
    Allow CraveLens to use Ollama
    1. Find the extension ID in chrome://extensions after loading CraveLens.
    2. Start Ollama with OLLAMA_ORIGINS=chrome-extension://gehijhngicamfekokcbcdkjnjkmfofpn.
    3. For local development, restart Ollama after changing the environment variable, then verify http://localhost:11434/api/tags works from the extension.
