# Local Gemma model

After accepting Google's Gemma license on Hugging Face, place the Web-converted
Gemma 3n E2B model here with this exact filename:

`gemma-3n-E2B-it-int4-Web.litertlm`

Download source:
https://huggingface.co/google/gemma-3n-E2B-it-litert-lm

The model is served only from the local CraveLens Node server and inference runs
inside the Chrome extension through LiteRT/MediaPipe WebGPU.
